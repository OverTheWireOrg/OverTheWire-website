Discord-IRC bridge: Installation
================================

The OverTheWire Discord-IRC bridge bot is **not available for public installation**.

The bot only works with the OverTheWire [Discord server][chat], where it connects the channels
to the matching channels on the OverTheWire [IRC server][chat]. Only OverTheWire staff can
install, configure and manage it. You cannot add it to other Discord servers or user accounts.

If you want to talk to the OverTheWire community, you don't need to install anything. Join our
Discord server or connect to our IRC server as described on the [Contact via Chat][chat] page.

If you want to run a similar bridge for your own community, you can use the open-source
[discord-irc][] software and set up your own bot.

Using the bridged channels is subject to the bridge [Terms of Service][tos] and
[Privacy Policy][privacy].
